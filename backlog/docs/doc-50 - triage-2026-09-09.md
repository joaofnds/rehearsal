says it reads active and completed task files and does not name the archive,

this run. The acyclic check walks the dependency chain of the card being
depended on; ACT-50's chain reaches ACT-52, while ACT-128 and ACT-132 have no
dependencies. So the block hits exactly those edges whose chain contains a
reissued id, which is a growing set.

ACT-90's own "not urgent: nothing is currently broken by it beyond ambiguous
references" is now stale and is annotated as such on the card. Its priority is
Low and was set deliberately, so triage did not change it; the raise is on the
list below.
